Summary

STORM is an open-source research system from Stanford's OVAL lab. It writes Wikipedia-style articles with citations by searching the web, simulating expert conversations and drafting an outline. Co-STORM adds a mode where a human takes part in the conversation. Results depend on the language model and search engine used. In seven independent evaluations (five peer-reviewed: EMNLP 2025 x2, ACL 2025, ACL 2026, ACL 2026 Findings), STORM produced complete cited articles but usually ranked below newer research systems. About 66-77% of citations supported the claims in one Wikipedia-generation study, and it scored 32.8-35.3 on DeepResearch Bench (50 = parity with the reference report). Co-STORM was tested in three of these studies with similar or lower results. The code has not changed since September 2025, and a July 2025 security report about disabled certificate checking remains unanswered. Overall score 56. Scope

This entry covers the open-source knowledge-storm library from Stanford’s OVAL lab (MIT licence), run with a language model and search engine chosen by the user. It includes both modes: STORM (automatic article writing) and Co-STORM (a human takes part in the research conversation); Co-STORM results are labelled below. The hosted research preview (storm.genie.stanford.edu) is not covered; no independent test of it was found.

Version and status note

Versions 1.0.0 (September 2024) to 1.1.1 (September 2025) are treated as one continuing library. The 2024 NAACL code branch is historical context; one study found v1.1.0 slightly stronger than it. The project is active but dormant: it is not archived and the research preview is online, but there have been no code changes since 30 Sep 2025.

Security and disputes

  • GitHub issue #375 (1 July 2025) reported an improper certificate validation problem and asked for a private disclosure channel. There has been no maintainer reply.
  • The current code (commit fb951af) downloads web pages with certificate verification disabled (verify=False).
  • No CVE, security advisory, legal or regulatory action, or Wikipedia-community action was found.

Uncertainties

  • Most independent results use LLM judges and relative scores, so they show how STORM compares with other systems rather than an absolute success rate.
  • Results depend on the language model and search engine. Most studies used GPT-4o-era or open models.
  • Only one study states the library version; the library has not changed since September 2025.
  • Co-STORM appears in three studies only; there is no independent test of its human-in-the-loop mode with real users.
  • The hosted research preview is not covered and was not independently tested.
