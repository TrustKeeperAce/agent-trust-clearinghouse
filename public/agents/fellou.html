Summary

Fellou is an AI browser from ASI X Inc. whose built-in agent plans and carries out multi-step web tasks across tabs, including scheduled tasks and actions in connected accounts such as Gmail. No counted independent evaluation was found. The one benchmark that ran Fellou (CAP, COLM 2026: 7.0% full success, 24.0% partial completion) lists FellouAI as an author affiliation, so it is not counted for Fellou. Fellou's own figures (80% on Online-Mind2Web; 72% on Web Bench) are not counted. Security researchers at Brave and LayerX showed that instructions placed on web pages could direct the agent to act on the user's behalf; LayerX reported no vendor response. Insufficient evidence for an overall score. Informational only; not a guarantee, endorsement, or certification.

Scope and version note

This entry covers the Fellou desktop browser and its built-in agent from Fellou 2.0 (3 June 2025) onward, treated as one continuous product; Fellou says earlier versions no longer work. Fellou does not publish version numbers after 2.0, so the exact version each source used is not known. The open-source Eko agent framework is not covered.

Affiliation disclosure

The CAP benchmark (COLM 2026) ran Fellou, but one of its authors did the work during an internship at FellouAI and FellouAI is listed as an affiliation. CAP is therefore not counted for this entry. It is counted, with this disclosure, on the Browser Use, Perplexity Comet and Manus entries.

Security reports

Brave, which makes a competing browser, reported to Fellou on 20 August 2025 that visible instructions on a web page the user asked Fellou to open could direct its agent; Brave published the finding on 21 October 2025 and did not state whether it was fixed. A reporter at The Register reproduced a similar result. LayerX, which sells browser security products, reported in its “BioShocking” research that a game-framed page led Fellou and five other agents to share credentials from a test repository; LayerX lists Fellou’s status as no response. These are demonstrations, not systematic tests. No CVEs, lawsuits or regulatory actions were found.

Privacy note

According to Fellou’s own privacy policy, the data controller is ASI X Inc. (Delaware) and personal data may be disclosed to third parties in the United States, Japan and Singapore. This has not been independently verified.
