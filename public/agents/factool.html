Summary

FacTool is open research code from GAIR-NLP that splits text into claims, searches the web for evidence and labels each claim true or false. Seventeen independent sources ran it (thirteen peer-reviewed), almost all as a comparison system in papers proposing alternative methods. On standard claim sets it labels true claims fairly well (F1 about 0.60-0.88) and false claims less well (about 0.46-0.64), and two studies report it as slower or costlier than newer checkers. One study found it overstated factual precision on long answers. The code has not changed since 2023; an unfixed medium-severity code-injection flaw (CVE-2025-4261) affects its math mode. Scope

The open-source FacTool framework (GitHub GAIR-NLP/factool and PyPI factool 0.1.x, 2023; code unchanged since about October 2023), which splits text into claims, searches for evidence and labels each claim, with modes for knowledge-based QA, code, math and scientific literature review. Tests that run FacTool's pipeline with a different language model count as tests of FacTool. Results for a language model alone (0039), Halu-J, and reuse of FacTool's datasets or prompts are not covered. Results depend heavily on the language model and search settings used.

How sources were counted

The FacTool paper, repository and package are the developers' own material and are not counted. Papers that run FacTool as a comparison system count, with their competing methods disclosed; tests of only the verification step count as component tests. Five counted papers come from one connected group of MBZUAI-affiliated authors and share some result rows. Papers that repeat earlier FacTool figures without a new run, use FacTool only as a metric, or adapt its prompts are listed as other. One study with a FacTool author is excluded.

Security and disputes

CVE-2025-4261 (published 5 May 2025; CVSS 4.0 score 4.8, Medium; local attack) describes code injection through exec() in FacTool's math mode, which runs model-generated code. It was reported in GitHub issue #50 in April 2025; no maintainer reply or fix was found. FacTool's code has not changed since about October 2023. No legal or regulatory action was found.

Uncertainties

  • Nearly every counted study proposes a competing method and reports FacTool as a baseline.
  • Five counted studies come from one connected group of MBZUAI-affiliated authors (Factcheck-Bench, OpenFactCheck, Loki, FIRE, UrduFactCheck); some reuse each other's FacTool rows, so they are not independent samples.
  • Studies use different language models (GPT-3.5 to GPT-4.1, LLaMA, Qwen) and search settings; figures describe FacTool with that model.
  • Three counted studies test only the verification step (Factcheck-Bench, OpenFactCheck, REVEAL); others apply FacTool outside its original tasks (summaries in FIZZ, agent trajectories in Phantom Merge, Urdu translations in UrduFactCheck, mitigation in Rowen).
  • No study states a FacTool version or commit; the code has not changed since about October 2023, so this is the only version.
  • One study with a FacTool author (Knowledge-Centric Hallucination Detection / RefChecker) is excluded under 0031.
