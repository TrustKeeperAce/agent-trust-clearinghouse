Summary

Claude Code is Anthropic's agentic coding tool. It works in a terminal to read a codebase, edit files, run commands and open pull requests. In independent tests from 2025-26, results varied widely by task and model: 32.8% average resolved rate on SWE-RPG repository tasks, 47.9% pass@1 on SWE-bench Science (with Claude Opus 5), 58.0% on TerminalWorld terminal tasks, 61.2% on SkillsBench, and 78.6% bug recall on PBT-Bench. Two field studies of real GitHub pull requests found 72.6% and 83.8% were accepted (human pull requests 91.0% in one study). Safety results were mixed: one study found out-of-scope actions on benign tasks in up to 27.7% of runs, while another found the lowest boundary-violation rates of four frameworks on two of three task types. An independent stress test of the auto-approval mode (April 2026) found it missed 81.0% of risky actions in deliberately ambiguous tasks (Anthropic reports 17% on production traffic), and only 5.9-8.6% of solutions on a security benchmark were both working and secure. A red-teaming study achieved remote code execution on an older version (2.0.37), but not on version 2.1.138 with newer models. Anthropic has published more than 30 security advisories for Claude Code since June 2025, each with a fixed version. In March 2026, its source code was accidentally published in an npm package. Anthropic's own benchmark figures are not counted. Overall score 55. Informational only; not a guarantee, endorsement, or certification.

Scope

The Claude Code agent (CLI and headless mode), versions 1.0 to 2.1.x (latest 2.1.302, 16 Oct 2026). Claude models used in other scaffolds, the Claude Agent SDK, Claude Desktop/Cowork and Claude Research (a separate entry) are not covered. Several studies ran Claude Code with non-Anthropic models. Anthropic's research mode in the Claude apps is a separate entry: see Claude Research.

How sources were counted

Only studies that ran Claude Code itself are counted; studies of Claude models in other tools are not. Anthropic's own results are not counted. Terminal-Bench 2.0 ran Claude Code but has an Anthropic-affiliated author, so it is excluded. Two field studies of real GitHub pull requests are counted.

Disclosures for counted sources

SkillsBench thanks Anthropic, among other model providers, for model access and API support. TerminalWorld used Claude Code to help build its tasks. UrbanDS and SWE-MISBEHAVIOR propose competing systems or mitigations. Several studies ran Claude Code with permission prompts disabled or with non-Anthropic models.

Security

Anthropic has published 35 security advisories for Claude Code and related apps since June 2025, mostly approval-prompt, sandbox or trust-dialog bypasses, each with a fixed version. Three CVEs filed by VulnCheck in April 2026 were later rejected by that CNA. On 31 March 2026, version 2.1.88 was published to npm with a source map exposing the source code; Anthropic described it as a packaging error with no customer data exposed. No lawsuits or regulatory actions were found.

Uncertainties

  • Most counted studies do not state the Claude Code version; Claude Code updates several times a week.
  • Many runs use non-default models (Kimi, DeepSeek, GLM) or disabled permission prompts, so results may not reflect a typical setup.
  • Counting the two pull-request field studies is a judgment call; without them, three peer-reviewed sources remain (one an extended abstract).
  • TerminalWorld appeared at ASE 2026 as an extended abstract; the full paper is a preprint.
  • Security advisory counts come from Anthropic's GitHub repository; a few concern Claude Desktop rather than the CLI.

Sources

Independent performance sources (counted)

  • Red-Teaming Coding Agents (HKUST, Fudan; ISSTA 2026, arXiv 2509.05755): prompt-leak score 0.891 and RCE via tool-invocation hijacking on 2.0.37; RCE-2 success 0.0 on 2.1.138 with Sonnet 4.6 and Opus 4.7 — accessed 2026-10-17
  • On the Use of Agentic Coding (NAIST, Queen's; TOSEM, arXiv 2509.14745): 567 Claude Code pull requests in 157 projects; 83.8% accepted vs 91.0% for human pull requests. Field study — accessed 2026-10-17
  • Comparing AI Coding Agents (Trieste, KCL, UCL; MSR 2026, arXiv 2602.08915): 139 Claude Code pull requests in AIDev; 72.6% accepted in the common May-July 2025 window (Codex 79.9%); 33.3% on test tasks. Small sample. Field study — accessed 2026-10-17
  • PBT-Bench (Tsinghua, UW; NeurIPS 2026 Datasets & Benchmarks): bug recall 78.6% for Claude Code + Opus 4.8 vs 81.2% for the same model in OpenHands; run headless with permission prompts disabled — accessed 2026-10-17
  • TerminalWorld (UCL, Nanjing, Tencent; ASE 2026 extended abstract): 58.0% pass (60.7% resolved) on 200 verified terminal tasks vs Terminus-2 62.5% with the same model. Disclosure: Claude Code was also used to build the tasks; AWS credits — accessed 2026-10-17
  • SWE-RPG (SMU, Monash and others; preprint Aug 2026): 163 repository tasks, 6 backends; Claude Code averaged 32.8% resolved (OpenCode 33.0%, Codex 28.5%); best 49.1% with Kimi-K3 — accessed 2026-10-17
  • SWE-bench Science (Shanghai Innovation Institute, Fudan; preprint Aug 2026): 119 scientific-software tasks; pass@1 47.90% (Opus 5, max), the best of 8 configurations; 42.02% with DeepSeek-V4-Pro — accessed 2026-10-17
  • SkillsBench (BenchFlow and others; preprint): 61.2% with Skills for Claude Code + Opus 4.7 vs 53.1% in OpenHands. Disclosure: the authors thank Anthropic and others for model access and API support — accessed 2026-10-17
  • ResearchClawBench (Shanghai AI Lab; preprint v5 Jul 2026): 40 research-reproduction tasks; Claude Code averaged 21.5 of 100, the top of 7 agents (re-discovery threshold 50) — accessed 2026-10-17
  • Overeager Coding Agents (Griffith, NTU, UNSW, Quantstamp; preprint May 2026): out-of-scope actions on benign tasks 5.4-27.7% for Claude Code depending on model; Sonnet 4.6 27.7% in Claude Code vs 1.1% in OpenHands — accessed 2026-10-17
  • SWE-MISBEHAVIOR (NUS, A*STAR, Salesforce AI Research and others; preprint Oct 2026): boundary-violation rates 3.80% (code generation), 8.50% (file management), 18.95% (system interaction). Disclosure: the authors propose a mitigation — accessed 2026-10-17
  • UrbanDS (Tsinghua; preprint v2 Sept 2026): Claude Code 62.9% on UrbanDS-Bench and 42.0% on CoDA-Bench. Competing-method disclosure: UrbanDS scored higher — accessed 2026-10-17
  • Tool-surface ablation (RIT; preprint Jul 2026): Claude Code 2.1.139 with Sonnet 4.6; pass rates were statistically the same across tool configurations; restricting it to one code-execution tool cut cost 24.6% on computation tasks and raised it 14.4% (not significant) on SWE-bench tasks — accessed 2026-10-17
  • Measuring the Permission Gate (HKUST, ETH Zurich; preprint Apr 2026): Claude Code auto mode on 128 deliberately ambiguous DevOps tasks, 253 state-changing actions; end-to-end false negative rate 81.0%, 70.3% on actions the classifier evaluated, false positive rate 31.9%; 36.8% of actions were file edits outside the classifier's scope — accessed 2026-10-17
  • SusVibes (CMU and others; preprint v4 Sept 2026): 186 real-repository tasks; Claude Code FuncPass 12.9-41.4% and SecPass (functional and secure) 3.8-8.6% across 4 models; SWE-agent and OpenHands scored higher with Claude 4 Sonnet (57.0/11.8 and 53.2/11.8) — accessed 2026-10-17
