Summary

Cline is an open-source coding agent that runs in VS Code, JetBrains IDEs or a terminal with a language model chosen by the user, and asks for approval before actions unless auto-approval is turned on. Twenty independent studies that ran it were found (eight peer-reviewed), most from 2026; thirteen are security studies. In task studies it was close to other harnesses with the same models in some settings (similar completion to OpenCode with GPT-5.3-Codex on ANCHOR; the highest success rate among assistants on GitChameleon 2.0 without a problem statement) and lower in others (31.2% against 37.8% for Claude Code on SWE-Nexus; 8.66% against 14.20% on SpreadsheetBench 2). Security studies found prompt injection, tool poisoning and malicious repositories leading to command execution in many configurations, often with auto-approval on; with approval required, one study found none of seven skill-file vulnerabilities still exploitable. Two high or critical CVEs in companion servers of the command-line tool have fixes in code, and independent researchers reported slow responses to several security reports in 2025 and early 2026. Informational only; not a guarantee, endorsement, or certification.

Scope

The open-source Cline agent from the cline/cline repository, run with a language model chosen by the user: the VS Code extension (v3.x through v4.1.25, 16 October 2026), the JetBrains plugin and the Cline command-line tool (through 3.0.73, 17 October 2026), including its use in GitHub Actions workflows. Companion servers started by the command-line tool (Kanban, Hub dashboard) are covered under disputes. Forks such as Roo Code and Kilo Code are separate products; their results are not counted here, even when reported in the same studies. Results depend heavily on the language model, the approval settings and the task.

How sources were counted

The Cline repository, documentation, blog, post-mortem and the cline-bench benchmark are the developers' own material and are not counted. Studies by independent authors that run unmodified Cline count, with competing or add-on methods disclosed; most compare it with other harnesses using the same models, and some use it as a fixed host to compare attacks or models. Results for forks (Roo Code, Kilo Code), agents built on Cline, studies of its prompt text or source code, and re-analyses of reports by others are listed as other or not counted. Security advisories and researcher write-ups are listed as other and inform the disputes factor.

Security and disputes

CVE-2026-44211 (GitHub advisory, 8 May 2026; CVSS 3.1 score 9.6, Critical; NVD status Analyzed) describes the Kanban server started by Cline CLI 2.13.0 and earlier accepting cross-origin WebSocket connections, so a website could read workspace data and send commands to agent terminals. The advisory and NVD list no patched version; an origin and host check was merged in the cline/kanban repository on 27 April 2026 and is in the kanban package from version 0.1.66 (27 April 2026). CVE-2026-59723 (GitHub advisory, 23 June 2026; CVSS 3.1 score 8.8, High; NVD status Analyzed) describes the Hub dashboard started by 'cline dashboard' accepting cross-origin connections and auto-approving tools in its sessions; NVD lists versions before CLI 3.0.30 (26 June 2026) as affected. On 17 February 2026 a leaked npm token was used to publish an unauthorized Cline CLI release (2.3.0) that installed an unrelated package; 2.4.0 replaced it about 8 hours later, and the VS Code and JetBrains extensions were not affected (GHSA-9ppg-jx86-fqw7, Low). The token had been exposed through a prompt-injection flaw in the project's own GitHub issue-triage workflow, reported privately on 1 January 2026 and addressed after public disclosure on 9 February 2026. Independent researchers also reported slow or no responses to security reports in 2025. No legal or regulatory action was found.

Uncertainties

  • Results reflect the model and the harness together; Cline is run with many different models.
  • Thirteen of the 20 counted studies are security studies, so evidence on everyday task completion is thinner than the source count suggests.
  • Most counted studies do not state the Cline version; the VS Code extension moved to v4.0.0 on 26 June 2026, and no counted study states a v4.x version.
  • The CVE-2026-44211 advisory and NVD list no patched version; the fix date is inferred from cline/kanban pull request #421 and the kanban 0.1.66 package.
  • Several 2025 security reports (Embrace The Red, IDEsaster) have no confirmed fix status for Cline.
  • Two pairs of counted studies share authors (SWE-Nexus and ANCHOR; Red-Teaming Coding Agents and Parasites in the Toolchain).
  • Several figures were read from tables in extracted text or PDF layouts.
  • Results for forks (Roo Code, Kilo Code) are not counted, even when reported in the same studies.

  • Red-Teaming Coding Agents from a Tool-Invocation Perspective (HKUST, Fudan; Proceedings of the ACM on Software Engineering, FSE 2026): six coding agents including Cline v3.20.8 (older models) and v3.82.0 (newer models); the authors' two-channel tool-hijacking attack (RCE-2) reached 1.0 success on Cline with Grok-4, Sonnet-4 and Sonnet-4.5, and on v3.82.0 still reached 1.0 with Gemini-3.1-pro and Grok-4.20. The authors credit Cline's system prompt with restricting commands from external sources, and report that 'Cline's default configuration lacks these safeguards' (command allowlisting or confirmation of high-risk tool calls). By default, 'all hosts except Cline display concise summaries' of tool calls, so Cline showed full details — accessed 2026-10-20
