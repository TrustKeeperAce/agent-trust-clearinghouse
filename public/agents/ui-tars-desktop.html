Summary

UI-TARS Desktop is a free, open-source app from ByteDance that lets an AI model operate a computer or browser by looking at the screen and using the mouse and keyboard. Most published results test ByteDance's UI-TARS models rather than this app, or come from ByteDance itself, and are not counted. The one independent test of the app found (Ohio State, preprint, Feb 2026) triggered a timing weakness in all 14 cases tried: a page that changed between when the agent looked and when it clicked led it to click the wrong thing, as with other screenshot-based agents. CVE-2026-81735 (CVSS 10.0, VulnCheck) concerned companion tool servers that accepted unauthenticated connections from the network; v0.3.1 changed the default to local-only. Insufficient evidence for an overall score. Informational only; not a guarantee, endorsement, or certification.

Scope and version note

This entry covers the UI-TARS Desktop app and Agent TARS (command line and web interface), which ship from the same repository and releases, from v0.2.x to v0.3.1 (8 October 2026). The UI-TARS models are not covered on their own: studies that tested only the model, not the app, are listed as context and not counted. The one counted study does not state the app version or model used.

Affiliation disclosure

UI-TARS Desktop is developed by ByteDance. Results from ByteDance and ByteDance Seed papers are not counted. No listed independent study has ByteDance authors.

Security

An independent study (Ohio State, preprint, February 2026) found that UI-TARS Desktop, like the other screenshot-based agents tested, could be led to act on a page that changed between observation and action in all 14 cases tried. CVE-2026-81735: MCP command and filesystem servers in the @agent-infra packages bound all network interfaces without authentication, allowing remote command execution. CVSS 10.0 (VulnCheck); NVD status Deferred. Default changed to localhost in v0.3.1; no authentication added to those servers. No lawsuits or regulatory actions were found.

Uncertainties

  • Full-text search coverage is incomplete; Semantic Scholar was rate limited on 17 and 19 October 2026.
  • The one counted study does not state the app version or model.
  • The CVE concerns MCP servers shipped with Agent TARS, not the Electron GUI itself.
