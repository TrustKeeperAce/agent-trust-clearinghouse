GPT Researcher

Category: Research · Type: open-source · Project repository · Last reviewed: 2026-10-16 (what this means)

Summary

GPT Researcher is an open-source research agent that writes cited reports. In independent evaluations (DeepResearchGym, ICTIR 2026; Deep Research Comparator, WWW 2026 Companion; TTD-DR preprint), results ranged from comparatively strong on citation quality to lower than a commercial deep-research system in head-to-head comparisons. Results vary with the AI model and search provider used. Informational only; not a guarantee, endorsement, or certification.

Security

Public vulnerability databases (NVD and GitHub Advisory Database) list 7 security advisories (2 Critical, 3 High, 2 Medium). The maintainer has fixed one; several others concern the self-hosted server, which the project's security policy says ships without built-in authentication and is intended for trusted environments only. Status may change; see linked sources.

Uncertainties

  • Results depend on the AI model and search provider used; the evaluations used differing, mostly 2025-era configurations.
  • Fix status of some advisories was not independently verified.
  • One independent evaluation (TTD-DR) is a preprint by authors comparing against their own system.
  • No independent completion-rate or cost data was found.
