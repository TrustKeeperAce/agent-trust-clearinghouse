Summary

GitHub Copilot CLI is GitHub's coding agent for the terminal, generally available since February 2026, which runs models from several companies. Five independent tests were counted, none peer-reviewed: a project-building benchmark, a documented hands-on review test and three security studies; two state the version tested (0.0.400 and 1.0.65). In the project benchmark it placed fourth of five agents with GPT-5 and with Claude Sonnet 4.5, and last of three with Gemini 3 Pro Preview; in the hands-on test it was level with Codex CLI on review tasks. Attacks in two security studies succeeded about as often as against other agents (89–96%). GitHub fixed two 2026 advisories on the day each was published (CVE-2026-29783 in 0.0.423 and CVE-2026-45033 in 1.0.43), but did not treat two other reports as vulnerabilities (an approval bypass, later changed in 1.0.3, and a model-dependent leak of secrets in autopilot mode). Many studies of Copilot CLI have Microsoft or GitHub authors and are not counted. Informational only; not a guarantee, endorsement, or certification.

Scope

GitHub Copilot CLI (the copilot command; npm @github/copilot) from its public preview (25 September 2025) through 1.0.103 (22 October 2026), in interactive, plan, autopilot and non-interactive (-p) use, with any model it offers. The retired GitHub Copilot in the CLI extension (gh copilot, 2023 to 25 October 2025) and the 2023 GitHub Next 'Copilot for CLI' preview are not covered. Copilot coding agent (the cloud agent, which has its own entry, including tasks that Copilot CLI hands to it), Copilot in Visual Studio Code and other IDEs, Copilot code review, products built on the Copilot CLI or its SDK, the unrelated AWS Copilot CLI, and results for models alone are not covered. Results depend heavily on the language model, the configuration and the task.

What this entry does not cover

GitHub has used the Copilot CLI name for three products. This entry covers only the current agent (the copilot command). The GitHub Copilot in the CLI extension (gh copilot), which suggested and explained single shell commands, was retired on 25 October 2025, and the 2023 GitHub Next preview is also not covered. GitHub Copilot coding agent, which works in the cloud on GitHub, has its own entry; tasks that Copilot CLI hands to it are covered there. Copilot agent mode in Visual Studio Code and other IDEs, Copilot code review, and products built on the Copilot CLI or its SDK are separate products, and studies of them are not counted. AWS Copilot CLI is an unrelated Amazon tool. Benchmarks that test models on their own, without Copilot CLI, describe the model, not this agent.

Model dependence

Copilot CLI offers models from Anthropic, OpenAI, Google and Microsoft, and an Auto setting that chooses one, so each result is for Copilot CLI together with a particular model and settings. In ProjDevBench its position against other agents changed with the model. In one reported attack, one model offered in Copilot CLI ran the attack chain in half of the attempts and two others refused; with Auto selected, the model used varied from session to session. Results for one model do not carry over to another.

How sources were counted

GitHub's own documentation, repository, changelog and blog posts, and studies with Microsoft or GitHub authors, are not counted (Decision 0031); many studies that ran Copilot CLI are in this group. Studies that ran Copilot CLI itself count once each, including security studies that attack it (see Decision 0087, D3), and documented hands-on tests with a stated method and results count (Decision 0071). Systems that use Copilot CLI as one part of a larger agent, and studies that used it as a tool for other research, are not counted. Security advisories and incident reports are described under disputes and are not counted as tests.

Security and disputes

On 25 February 2026, the day Copilot CLI became generally available, PromptArmor reported that a prompt injection in a cloned repository could make it download and run code without asking, because the env command was on its built-in read-only list (macOS). According to PromptArmor, GitHub replied the next day that this was a known issue that did not present a significant security risk and was not eligible for a bounty; the 1.0.3 changelog (9 March 2026) lists a change so that env commands need approval. CVE-2026-29783 (high; GitHub CVSS 4.0 score 7.1, NVD record 7.5), published on 6 March 2026: crafted shell parameter expansions could make a command look read-only and run hidden commands, even in modes that ask before writes; it affects 0.0.422 and earlier and is fixed in 0.0.423, released the same day. CVE-2026-45033 (medium on GitHub's advisory; high, 8.5, on the CVE record), published on 6 May 2026: a bare git repository hidden inside a project could run commands during ordinary git operations; it affects 1.0.42 and earlier and is fixed in 1.0.43, released the same day (the advisory text says "prior to 1.0.42"). In October 2026 Adversa AI reported that, in autopilot mode, a web page with encrypted instructions led Copilot CLI to send a local secrets file to an attacker when one of the offered models handled the session. GitHub validated the report but said it was not a product vulnerability, because the user had directed the agent to fetch the content with full permissions; Adversa says it still reproduced on 1 October 2026. A user reported on 25 February 2026 that restoring a checkpoint permanently deleted untracked files the agent had not created; rewind was changed in 1.0.78 (3 August 2026) to restore only files Copilot changed, and the report was closed in September 2026. No lawsuit or regulatory action concerning Copilot CLI was found.

Uncertainties

  • Results reflect the model and the harness together; Copilot CLI offers models from several companies and an Auto setting that picks one, so results for one model may not carry over.
  • Copilot CLI releases several times a week (1.0.103 on 22 October 2026); only two counted tests state a version (0.0.400 and 1.0.65), and approval behaviour changed in 0.0.423, 1.0.3 and 1.0.43.
  • The name has been used for three GitHub products: the 2023 GitHub Next 'Copilot for CLI' preview, the gh copilot extension retired on 25 October 2025, and the current agent; some studies say only 'GitHub Copilot', and studies of the VS Code extension are not counted here.
  • The B grade depends on counting one documented hands-on test from a developer blog; without it the entry would be B- with an overall score of 46.
  • Many studies that ran Copilot CLI have Microsoft or GitHub authors and are not counted; they include results both more and less favourable than the counted ones.

Independent performance sources (counted)

  • ProjDevBench: Benchmarking AI Coding Agents on End-to-End Project Development (Lu, Zhang, Hou and others; UC Merced, Shanghai Jiao Tong University, Shanghai Innovation Institute, Beijing Institute of Technology; preprint, February 2026): 20 end-to-end project tasks judged by an online judge and code review, six agents run through their command-line interfaces (the setup installs the @github/copilot package). Final weighted scores for GitHub Copilot CLI were 61.73 with GPT-5 (fourth of five; others 57.34 to 77.85), 67.18 with Claude Sonnet 4.5 (fourth of five; others 60.41 to 70.88) and 55.32 with Gemini 3 Pro Preview (last of three; Gemini CLI 68.61, Cursor 75.32); with Sonnet 4.5 its execution score fell from 71.10 on easy tasks to 36.63 on hard ones. One run per configuration. Version not stated — accessed 2026-10-23
  • Documented hands-on test (individual developer, Zenn, 2 February 2026; updated 19 August 2026): 180 timed runs (90 per tool) of five code-review tasks (explanation, review, plan review, improvement proposals, bug finding) with Copilot CLI 0.0.400 and Codex CLI 0.93.0, both with GPT-5.2 at the highest reasoning setting, measured on 1 February 2026. Mean response time was 48.05 seconds for Copilot CLI and 48.19 for Codex CLI (no significant difference); blind quality scores by an AI judge were 26.67 and 28.18 out of 30, which the author treats as within the margin of error; Codex CLI produced more output per second (16.5 against 25.7 seconds per KB). Review tasks only; the author was not sure the reasoning setting was applied identically. Counted as a documented test (Decision 0071; Decision 0099, D4) — accessed 2026-10-23
  • MOSAIC: Knowledge-Guided CLI Command Composition Attack in LLM Coding Agents (Wu, Wang, Nan, Zhang, Wang; Sun Yat-sen University, Shandong University, Peking University, HKUST; preprint, July 2026): attacks that split a harmful action into ordinary command-line commands. Each agent ran in its default configuration with five models. Attacks succeeded against GitHub Copilot CLI in 486 of 505 cases (96.24%), against 95.84% to 97.43% for Claude Code, Codex CLI, Gemini CLI and Trae Agent. Version not stated (documentation accessed 8 June 2026). Security study — accessed 2026-10-23
  • OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution (Chen, Wang and others; Fudan University, Shanghai AI Laboratory, XSafeAI; preprint, August 2026, revised September 2026): long-horizon red-teaming scenarios built from real tools, MCP servers and skills, run on 15 deployed agents with five models. Copilot CLI's strict attack success averaged 89.1% (65.4% with Claude Opus 4.8 to 100% with Qwen-3.7-Max), against 59.1% for Aider and 79.1% to 90.3% for the other 13 agents, including Claude Code (89.7%) and OpenCode (90.3%). Version not stated. Security study — accessed 2026-10-23
  • Agent Approval Laundering: Transitive Effects Beyond the Approved Invocation (Zhang, Xia and others; Institute of Information Engineering, Chinese Academy of Sciences, Beihang University, BUPT; preprint, September 2026): whether what a user approves matches what then happens. With GitHub Copilot CLI 1.0.65 (one of six product configurations), an approved, named MCP documentation-tool call also used network access that the approval record did not show; Qwen Code showed the same gap and Claude Code a related one with a package install. The authors disclosed the findings to GitHub. Security study — accessed 2026-10-23
