Summary

Loki is an open-source fact-checking tool from Libr-AI (an MBZUAI-linked group). It splits text into claims, checks which are worth verifying, searches the web for evidence and gives a verdict for each claim, with the evidence shown so a person can judge. Two independent studies ran Loki as a comparison system. On FacTool-KBQA it reached F1 0.76 on non-factual and 0.67 on factual claims (Proof-of-Guardrail, USC/Sahara AI). Adapted to health claims in TikTok influencer videos, it reached macro-F1 0.43 (TAIGR, Purdue). The developers' own figures from their COLING 2025 demo paper are not counted. The repository has had no code changes since June 2024 and the hosted demo did not respond on 17 October 2026. No CVEs or security advisories were found. Insufficient evidence for an overall score. Scope and version note

Results depend on those choices. The hosted demo (loki.librai.tech) is not covered; it did not respond on 17 October 2026.

Maintenance note

The repository has had no code changes since June 2024; the last commit (October 2024) changed only the README. It is not archived.

Related entry and shared authors

Loki and OpenFactCheck share MBZUAI-linked authors (Yuxia Wang, Minghan Wang, Preslav Nakov); Libr-AI is MBZUAI-linked. They are separate code bases with different purposes and are assessed separately. See OpenFactCheck (open-source).

Independent performance sources (counted)

  • Proof-of-Guardrail in AI Agents (preprint, Mar/Jun 2026; Sahara AI and University of Southern California): runs Loki as a fact-checking guardrail on FacTool-KBQA. Non-factual P 0.71 / R 0.81 / F1 0.76; factual P 0.74 / R 0.61 / F1 0.67; mean latency 20.4 s with Loki vs 16.0 s without, in a trusted execution environment — independent performance, accessed 2026-10-17
  • TAIGR (preprint, Jan 2026; Purdue University): Loki adapted as a baseline for validating health claims in TikTok influencer videos (PubMed evidence, GPT-4.1-mini). Macro-F1 0.43 (Incorrect 0.71, Partially correct 0.29, Correct 0.29) vs TAIGR 0.52. Task differs from Loki's design (implicit takeaways, not explicit claims) — independent performance, accessed 2026-10-17
