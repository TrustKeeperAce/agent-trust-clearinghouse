Summary

OpenCode is an open-source coding agent for the terminal from Anomaly (formerly SST), run with a language model the user chooses. 28 independent studies that ran it were counted, 8 of them peer-reviewed (ISSTA, KDD, ICML, ASE, ESEM and CAMLIS 2026), and several state the version tested, from v1.1.44 (January 2026) to 1.18.31 (September 2026). Results depend heavily on the model: with the same model OpenCode scored above some harnesses and below others, and with weaker or incompatible models its results fell sharply. Seven counted studies attacked OpenCode itself, and planted instructions often succeeded, mostly with confirmations turned off. Three security advisories were published for OpenCode's local server and web interface in 2026 (CVE-2026-22812, CVE-2026-22813 and GHSA-632h-h47v-g4x4); each was fixed, and for CVE-2026-22812 the initial report went unanswered for several weeks. An older, archived Go project also used the name OpenCode; it is a different product. Informational only; not a guarantee, endorsement, or certification.

Overall score: 54 · Evidence grade: A · Independent sources: 28 performance (8 peer-reviewed), 19 other

Scope

OpenCode from the anomalyco/opencode repository (formerly sst/opencode), from its 2025 releases through v1.19.3 (16 October 2026), in its terminal interface, desktop and web clients and `opencode serve` server, run with any language model and provider the user chooses. The older Go project of the same name (opencode-ai/opencode, archived and continued as Crush by Charm) is a different product, and studies that tested it are not counted. Systems that use OpenCode as one part of a larger agent, and third-party plugins such as oh-my-opencode, are not covered. Results depend heavily on the language model, the configuration and the task.

Which OpenCode

Two projects have used the name OpenCode. The one covered here is anomalyco/opencode (formerly sst/opencode), written in TypeScript and maintained by Anomaly. An earlier Go project, opencode-ai/opencode, was active from March to June 2025, is now archived and continues as Crush under Charm. Both repositories carry a v0.0.55 tag. Some papers cite the Go project's address but state a version that exists only in the current project (for example v1.4.0); those are counted here. Results for the Go project or Crush are not counted.

Model dependence

OpenCode does not come with its own model, so every result is for OpenCode together with a particular model and settings. With the same model, studies found OpenCode level with or above some harnesses (SWE-RPG, StaminaBench, BioXArena, Timeline-Bench, PERFOPT-Bench) and below others (SWE-Bench Mobile, SWE-Nexus, What Does a Harness Buy?). With small or poorly matched open models its results fell sharply, for example 8.4% for a model whose tool-call format OpenCode could not parse. Results for one model do not carry over to another.

How sources were counted

Anomaly's own documentation, repository and announcements are not counted. Studies that ran OpenCode itself count once each, including fixed-harness benchmarks that compare models inside OpenCode and security studies that attack it (see Decision 0087, D3). Studies whose authors' own coding agent or model is in the comparison (Qoder in two Alibaba-related papers; Zhipu's GLM models in MTAC-IFBench) are listed but not counted. Systems that use OpenCode as one part of a larger agent, third-party plugins, source-code taxonomies, repository-mining studies and studies of the older Go project are listed as other or not counted. Security advisories and the terms-of-service dispute are described under disputes and are not counted as tests.

Security and disputes

Three GitHub security advisories have been published for OpenCode. CVE-2026-22812 (high, CVSS 8.8), reported by GitHub user CyberShadow: versions before 1.0.216 started a local server without authentication that any website could use to run commands. According to the reporter, an email to the maintainers on 17 November 2025 went unanswered; after a GitHub advisory was filed on 27 December 2025 and a public issue followed, the fix shipped in 1.0.216 on 30 December 2025, and on 9 January 2026 the maintainers wrote that the report had been "dropped over the holidays" and that the server no longer starts by default (from 1.1.10). CVE-2026-22813 (critical, CNA score 9.4; NVD score 6.1), reported by GitHub user AlbertSPedersen: cross-site scripting in the web interface could lead to command execution; fixed in 1.1.10. Both advisories were published on 12 January 2026. On 12 January 2026 the maintainer (thdxr) wrote on issue #6355 that the team had "done a poor job handling these security reports" and was meeting with people to advise it on handling them better, "get a bug bounty program funded and have some audits done"; the Clearinghouse could not confirm that these plans have been carried out. GHSA-632h-h47v-g4x4 (high, 7.5), reported by Christophe Tafani-Dereeper of Datadog Security Labs: from 1.14.30 to 1.18.21 the upgrade endpoint of a running `opencode serve` could be made to install an attacker's npm package; reported on 11 August 2026 and fixed in 1.18.22 on 24 August 2026. Datadog thanked Anomaly for open communication and a quick patch, and reports that Anomaly chose not to request a CVE, so this flaw has no CVE identifier. In January 2026 Anthropic blocked the use of Claude Pro and Max subscriptions in OpenCode and other third-party harnesses; a user reported an account ban, and a maintainer later wrote that Anthropic's lawyers had demanded that the issue be closed. Anthropic makes Claude Code, a competing product. No lawsuit or regulatory action concerning OpenCode was found.

Uncertainties

  • Results reflect the model and the harness together; OpenCode is run with many different models, and with the same model its results ranged from well below to level with other harnesses.
  • Two different products have used the name OpenCode. Some papers cite the archived Go project's address while testing the current one, and one peer-reviewed study (DCAS) states 'v0.0.55', a version number both projects used.
  • OpenCode releases very often (716 releases in 278 days by one count), so tested versions age quickly; no counted test names a v1.19 release.
  • Seven of the 28 counted studies are attack studies, mostly run with confirmations off; their results describe OpenCode under attack, not in everyday use.
  • The fix for GHSA-632h-h47v-g4x4 has no CVE; scanners that rely on CVE identifiers may not flag affected versions (1.14.30 to 1.18.21).
