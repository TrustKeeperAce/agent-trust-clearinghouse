Summary

Google Jules is Google's asynchronous coding agent: it works on a GitHub repository in a cloud virtual machine and returns its changes as a pull request. It entered public beta in May 2025 and left beta in August 2025. Three independent sources that measured it were found, none peer-reviewed: two studies of pull requests in a public dataset of agent activity on GitHub (one in a journal whose review process could not be confirmed) and a newsletter report that gave 15 coding tools the same build task. None names the Jules version, and all predate the Gemini 3 updates, so the current version has not been independently tested. The score rests on the minimum of three counted sources. In May 2025 an independent security researcher showed that instructions hidden in a web page or GitHub issue could make Jules leak data and run downloaded malware; he reported this to Google, which, according to him, closed the report as an issue it was already tracking. No CVE, lawsuit or regulatory action concerning Jules was found. Informational only; not a guarantee, endorsement, or certification.

Scope

Google Jules, the hosted coding agent at jules.google that plans a task, edits code and runs commands in a cloud virtual machine and publishes the result to GitHub as a branch or pull request (by default from the google-labs-jules[bot] account): the public beta from 19 May 2025, general availability from 6 August 2025 (Gemini 2.5 Pro), and later updates including Gemini 3 Pro (November 2025), Gemini 3 Flash as the base model (January 2026) and Gemini 3.1 Pro for Pro-plan users (March 2026), whether a task is started in the web app, from a GitHub issue label, with the Jules Tools command-line interface or through the Jules API. The December 2024 research configuration that Google benchmarked on a SWE-bench subset, other Google coding products (Gemini CLI, Gemini Code Assist including its pull-request reviewer, Google Antigravity, Firebase Studio, AlphaEvolve) and results for Gemini models alone are not covered. Results depend heavily on the language model, the configuration and the task.

How sources were counted

Google's blog posts, changelog, documentation and benchmark results (including the December 2024 SWE-bench Verified result for a research version of Jules) and papers written by Google staff are the developer's material and are not counted. A peer-reviewed study with a co-author from GitHub, which makes GitHub Copilot, compares Jules with Copilot and is listed but not counted. Studies of pull requests opened by Jules on GitHub count once each, even when they use the same public dataset; one is in a journal whose review process could not be confirmed and is counted as not peer-reviewed. A newsletter report that gave 15 tools the same build task counts as a documented test. Security research, usage dashboards, dataset statistics and single-user reports are listed as other. Other Google coding products (Gemini CLI, Gemini Code Assist, Google Antigravity, Firebase Studio, AlphaEvolve) and results for Gemini models alone are not counted.

Security and disputes

In May 2025 independent security researcher Johann Rehberger (Embrace The Red) showed that instructions planted in a web page or GitHub issue could make Jules send data to an outside server, download and run command-and-control malware, and follow hidden Unicode instructions to add backdoor code. Some steps happened before the user approved a plan, and plans were approved automatically after a delay. He reported the findings to Google on 21 May and 1 June 2025 and published them on 13 to 15 August 2025. He writes that Google triaged the second report as an abuse risk and closed it on 13 June 2025 as something the team was already tracking, and that his questions about a mitigation timeline were not answered. No public statement from Google on a fix was found; the Jules FAQ still describes a virtual machine "with internet access" and says users are responsible for the code they run. These are one researcher's demonstrations, not independent rates. No CVE or GitHub security advisory for Jules was found (NVD and GitHub, 20 October 2026; the NVD records matching "jules" concern WordPress plugins by a developer of that name). No lawsuit or regulatory action concerning Jules was found.

Uncertainties

  • No counted test names the version or model of Jules it used; their data come from the beta and the Gemini 2.5 Pro period (May to October 2025). The Gemini 3 models and the features added since November 2025 are untested.
  • Merge rates measure whether maintainers accepted a pull request, not whether the task was done correctly; they also depend on how much human review happens and on repository popularity, and most Jules pull requests went to unstarred repositories.
  • According to the AIDev maintainers, pull requests from the Jules bot account fell about fifteen-fold after late January 2026. Since February 2026 Jules can also commit under the user's own name, which may make later activity harder to identify.
  • The prompt-injection findings are one researcher's demonstrations from May 2025; whether Google has since changed this behaviour was not established.
  • The score rests on the minimum of three counted sources: if any one of them were not counted, the entry would not have enough evidence to be scored. Two of the three use the same dataset (AIDev v4).

Sources

Independent performance sources (counted)

  • Merged, Not Measured (Qi, Li, Chen and others; University of Arizona, Wuhan University and others; preprint, September 2026): 1,262 performance fixes by six agents in the AIDev v4 dataset (pull requests in repositories with more than 100 stargazers, up to 24 October 2025). Jules opened 17 of them; of its 15 closed fixes in 6 repositories, 11 (73%) were merged, the same share as OpenAI Codex and Claude Code and above GitHub Copilot (50%), Cursor (42%) and Devin (30%). Jules pull requests come from a bot account, and someone else merged them in every case where the merger is recorded. Small Jules sample. The authors declare no conflict of interest. Field study — accessed 2026-10-20
  • AI Coding Agents on GitHub: Repository Popularity as a Hidden Confounder (Bhavnagri, Wilson College, University of Mumbai; IJRASET 14(IX), September 2026): all 2,743,854 pull requests by six agents in AIDev v4 (24 December 2024 to 24 October 2025). Jules: 38,691 of 43,600 decided pull requests merged (88.74%; OpenAI Codex 93.20%, Claude Code 87.84%, Cursor 80.39%, GitHub Copilot 77.63%, Devin 69.74%); 76.4% of Jules pull requests went to unstarred repositories and 0.95% to repositories with 100 or more stargazers, and its merge rate fell 16.6 points across the four popularity bands with enough data. Holding the repository fixed halved the pooled Cursor–Jules difference (odds ratio 2.063 to 1.370, 101 repositories). Limited: a journal whose review process could not be confirmed (counted as not peer-reviewed, as in Decision 0076). Field study — accessed 2026-10-20
  • June 2025 Coding Agent Report (Will Schenk, TheFocus.AI, for the Turing Post newsletter, 5 June 2025): 15 coding tools each given the same prompt to build a small Node.js web app with Docker and unit tests in an empty repository, with plans accepted without review; outputs built and run by hand and scored on five 1–5 criteria with help from an AI code review (Claude Sonnet). Jules scored 21 of 25 (code 4, testing 5, tooling 4, documentation 4, professionalism 4), level with GitHub Copilot's coding agent and below Cursor's background agent, v0 and Warp (24 each). One build per tool; the generated repository is public (github.com/The-Focus-AI/idears-jules). No funding disclosed — accessed 2026-10-20
