Summary

OpenAI Codex is OpenAI's coding agent, available as an open-source command-line tool, an IDE extension and desktop app, and a cloud agent that opens pull requests. Twenty-six independent studies that ran it were found (five peer-reviewed). Results depend heavily on the model and task. Codex CLI had the highest score in several 2026 benchmarks, for example 63% on Terminal-Bench 2.0 with GPT-5.2 and 42.50% on cross-repository changes (WideSWE), but it trailed Claude Code or OpenCode on others, and hard multimedia and research tasks stayed low (16.2-26.8%). In field studies of public GitHub pull requests, cloud Codex pull requests had the highest acceptance rates of the agents compared (64% and 59.6-88.6%). Out-of-scope actions on benign tasks were measured at 5.4-13.5%. Seven CVEs affecting Codex CLI or the desktop app have been published; fixes are referenced for most. Scope

The Codex agent products launched from April 2025: Codex CLI (including headless exec), the IDE extension and desktop app, and the cloud Codex agent that opens pull requests, through Codex CLI rust-v0.163.0 (15 October 2026). The 2021 Codex model behind early GitHub Copilot, and GPT-Codex models run inside other harnesses, are not covered. Results depend heavily on the language model and task.

How sources were counted

OpenAI's own reports and OpenAI co-authored benchmarks (for example EVMbench) are not counted. No counted study has OpenAI authors. Studies that acknowledge OpenAI gifts, credits or API support are counted with disclosure. Pull-request field studies of the cloud agent count. Studies that only run GPT-Codex models in other harnesses are not evidence about this product.

Security

Codex runs commands written by the model, by default inside a sandbox with approval prompts. Seven CVEs affecting Codex CLI or the desktop app were published between 2025 and 2026, including sandbox and approval bypasses and commands run from repository configuration. A GitHub advisory reports CVE-2025-59532 patched in 0.39.0. OpenAI published the 2026 CVEs with fix pull requests referenced. No legal or regulatory action specific to Codex was found.

Sources

Independent performance sources (counted)

  • BountyBench (Stanford; NeurIPS 2025): real-world bug-bounty systems; Codex CLI with o3-high detected 12.5% and patched 90%; with o4-mini patched 90%; Codex CLI and Claude Code stronger at defence than offence — accessed 2026-10-17
  • Terminal-Bench 2.0 (ICLR 2026): Codex CLI with GPT-5.2 had the highest average resolution rate (63%); with GPT-5-Nano it resolved far fewer tasks. No OpenAI authors (an Anthropic co-author excludes it for Claude Code only) — accessed 2026-10-17
  • Comparing AI Coding Agents (Trieste, KCL, UCL; MSR 2026, arXiv 2602.08915): OpenAI Codex pull requests in AIDev accepted at 59.6-88.6% across nine task types, highest of five agents; 79.9% in the common May-July 2025 window. Field study — accessed 2026-10-17
  • MT-Sec (University of Maryland; EMNLP 2026 per author homepage): Codex + GPT-5 (thinking) correct-and-secure 50.1% single-turn, falling to 29.0% in one multi-turn setting (overall 36.2%). Disclosure: the authors acknowledge gifts from OpenAI and Google DeepMind — accessed 2026-10-17
  • TerminalWorld (UCL, Nanjing, Tencent; ASE 2026 extended abstract): Codex CLI with GPT-5.5 passed 48.5% (56.1% resolved) of 200 verified real-world terminal tasks — accessed 2026-10-17
  • The Rise of AI Teammates in SE 3.0 (Queen's University; AIDev dataset; preprint): OpenAI Codex pull requests accepted at 64%, vs Devin 49% and GitHub Copilot 35%. Field study — accessed 2026-10-17
  • SkillsBench (BenchFlow and others; preprint): Codex + GPT-5.5 66.5% with Skills (OpenHands with the same model 67.3%). Disclosure: the authors thank OpenAI and other model providers — accessed 2026-10-17
  • SWE-RPG (SMU, Monash and others; preprint Aug 2026): 163 repository tasks across backends; Codex averaged 28.5% resolved (Claude Code 32.8%, OpenCode 33.0%) — accessed 2026-10-17
  • ResearchClawBench (Shanghai AI Lab; preprint): research-reproduction tasks; Codex CLI averaged 18.4 of 100 (Claude Code 21.5) — accessed 2026-10-17
  • SWE-bench Science (Shanghai Innovation Institute, Fudan; preprint): Codex configurations kept 93.28-98.32% of passing tests passing; best overall pass@1 was a Claude Code configuration (47.90%) — accessed 2026-10-17
  • Overeager Coding Agents (Griffith, NTU, UNSW, Quantstamp; preprint May 2026): out-of-scope actions on benign tasks 5.4-13.5% for Codex CLI depending on model (Claude Code 11.8-27.7%, OpenHands 0.2-4.5%) — accessed 2026-10-17
  • SNARE (Griffith, Quantstamp and others; preprint May 2026): synthesised scenarios elicited overeager behaviour in 11.2% of Codex CLI runs (Claude Code 19.6%, Gemini CLI 11.0%, OpenHands 42.8%). Disclosure: overlaps in authors with Overeager — accessed 2026-10-17
  • Tool-surface ablation (RIT; preprint Jul 2026): restricting Codex to code execution cut cost by 19.9% on SWE-bench tasks without a significant pass-rate change — accessed 2026-10-17
  • ABTest (York, Polytechnique Montreal, Concordia; preprint Apr 2026): behaviour-anomaly rate 59.9% for Codex CLI + GPT-5.1-Codex-Mini and 28.4% with GPT-4o-mini (range across agents 23.1-59.9%) — accessed 2026-10-17
  • The Amazing Agent Race (Minnesota, Yonsei, Grammarly; preprint): Codex CLI about 37% accuracy; Claude Code matched it with about 6x fewer tokens — accessed 2026-10-17
  • TEBench (Nanjing University and others; preprint May 2026): project-level test evolution; Codex CLI had the highest composite score (72.3%) and executability (99.2%) of five configurations — accessed 2026-10-17
  • SWE Atlas (Scale AI; preprint May 2026): GPT-5.4 in Codex had the highest pass@1 (43.49%), ahead of Opus 4.7 in Claude Code (41.89%). Disclosure: Scale AI runs commercial leaderboards — accessed 2026-10-17
  • MMTB (POSTECH, Krafton; preprint May 2026): Codex CLI with GPT-5.2 solved 16.2% of multimedia-file terminal tasks — accessed 2026-10-17
  • Push Your Agent (preprint May 2026): Codex CLI solved many 50-artifact counting tasks but only 3 of 9 per condition at 100 artifacts — accessed 2026-10-17
  • Life After Benchmark Saturation: CORE-Bench (Princeton and others; preprint Jun 2026): Codex CLI configurations reached 92.3-97.4% on the corrected CORE-Bench Hard. Disclosure: compute credit from OpenAI — accessed 2026-10-17
  • RuBench (independent researcher; preprint v2 Jul 2026): Russian-specification repository tasks; Codex CLI + GPT-5.5 66.7% pass@1 vs Claude Code + Opus 4.8 78.7% — accessed 2026-10-17
  • WideSWE (Zhejiang, Tsinghua; preprint Sep 2026): cross-repository changes; Codex CLI + GPT-5.6-sol had the highest full success (42.50%) of seven configurations — accessed 2026-10-17
  • Timeline-Bench (TensorTest; preprint Sep 2026): video-editing tasks; GPT-6 Astra in Codex with editorial guidance resolved the most tasks, 15 of 56 (26.8%) — accessed 2026-10-17
  • SWE-Duel (SMU; preprint Oct 2026, under review): GPT-5.5 with Codex CLI ranked first, repairing 98.3% of the defects it reviewed — accessed 2026-10-17
  • 1GC-7RC (University of the Bundeswehr Munich; preprint May 2026): seven ML research tasks on one GPU; Codex often stopped early, using about 50% of its time budget on average — accessed 2026-10-17
  • HarnessSecurity-Bench (Sun Yat-sen University and others; preprint Oct 2026): tested whether security settings in six harnesses, including Codex CLI (approval policy, sandbox, network), block attacks; protections varied by mechanism and task — accessed 2026-10-17
