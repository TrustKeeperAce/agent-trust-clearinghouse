Summary

Data Interpreter is an open-source data-science agent in the MetaGPT framework. It plans analysis and machine-learning tasks as a graph and writes and runs Python code step by step. Nine independent studies that ran it were found (two peer-reviewed). Its results depend heavily on the model and task. On InfiAgent-DABench, independent re-runs scored 54-80%, against the 94.93% the developers reported; two papers say they could not reproduce that figure. Results ranged from mid-pack on Kaggle-style tabular tasks to 3.3% on an urban data benchmark. In a security study it had the lowest attack success rate of four open-source data agents, but the authors attribute this to limited functionality rather than stronger defences. Seven CVEs have been published for MetaGPT, including two that affect Data Interpreter directly. The project has had no release since March 2025 and no commits since January 2026. Scope

The open-source Data Interpreter role in MetaGPT (metagpt/roles/di), run with a language model chosen by the user; MetaGPT releases through 0.8.2 (9 March 2025). MetaGPT's other roles and the commercial MGX / MetaGPT X service are not covered. Results depend heavily on the language model and task, so results are reported as ranges by model.

Version and status note

Data Interpreter is treated as one continuous component from its 2024 release through MetaGPT 0.8.2. The project appears dormant: the last PyPI release was 0.8.2 (9 March 2025) and the last commit to the repository was on 21 January 2026. The repository is not archived.

Disclosures for counted sources

Eight of the nine counted studies propose a competing data-science agent and compare it against Data Interpreter. The ninth, Data Agents Under Attack, is a security study.

Disputes: reproduction gap

The developers report 94.93% on InfiAgent-DABench with GPT-4o. DatawiseAgent (EMNLP 2025) and DataMind (ICLR 2026) report that they could not reproduce this; their re-runs scored 54.09–75.78% depending on the model. This is the papers’ finding; the difference may reflect evaluation settings.

Security

Data Interpreter runs Python code written by the model. Published CVEs (scores as assigned by the named scorer; status as listed by NVD on 17 October 2026):

Data Interpreter components

  • CVE-2026-4516: injection in metagpt/actions/di/write_analysis_code.py, MetaGPT up to 0.8.1. CVSS 3.1 6.3 (VulDB). NVD status: Analyzed. VulDB records that the vendor did not respond. No fix identified.
  • CVE-2026-19058: code injection in metagpt/roles/di/data_interpreter.py, up to 0.8.2, local attack. CVSS 3.1 5.3 (VulDB). NVD status: Deferred. No fix identified.

MetaGPT framework

  • CVE-2026-0760 (deserialize_message) and CVE-2026-0761 (actionoutput_str_to_mapping): CVSS 3.0 9.8 (Zero Day Initiative). Reported to the vendor on 19 September 2025 and published as 0-day advisories on 9 January 2026 after no vendor update. NVD status: Analyzed.
  • CVE-2024-23750: QaEngineer role, MetaGPT through 0.6.4. CVSS 3.1 8.8 (NIST).
  • CVE-2026-19059 (editor.py path traversal) and CVE-2026-19060 (code injection), up to 0.8.2, local attack. CVSS 3.1 3.3 and 5.3 (VulDB). NVD status: Deferred.

The project has not published any GitHub security advisories. In the Data Agents Under Attack study, Data Interpreter had the lowest attack success rate of four open-source data agents (about 12.9% on average). The authors attribute this to limited functionality (it often failed to connect to the database) rather than stronger defences. When attacks did connect, it had the largest share of the most severe outcome level (9.3%).

Uncertainties

  • Results vary widely by model and benchmark; no single figure represents the agent.
  • Eight of nine sources are competing-agent papers (all disclosed); only two are peer-reviewed.
  • Whether 2026 studies used 0.8.2 or later main-branch code is mostly unstated.
  • No fixes have been identified for the Data Interpreter CVEs; the project appears dormant.
