Summary

Browser Use is an open-source Python library (MIT licence) that lets a language model of the user's choice control a web browser to carry out tasks. Results depend heavily on the model used. In independent evaluations (Online-Mind2Web, COLM 2025; Princeton's Holistic Agent Leaderboard; CAP, COLM 2026; a 2026 preprint), success rates ranged from about 2–5% full success on hard cross-site tasks to 18–45% on live-website benchmarks, well below the vendor's own figures. Independent security studies (VPI-Bench, ICLR 2026; two preprints) found it often followed instructions hidden in web pages, and a domain-restriction bypass (CVE-2025-47241) was fixed in version 0.1.45. The vendor's Cloud service is not covered. Overall score 51. Informational only; not a guarantee, endorsement, or certification.

Scope

This entry covers the open-source browser-use Python library (MIT licence) run with a language model the user chooses. Results depend heavily on that model, so independent results are shown as ranges across the models tested. Browser Use Cloud and the vendor’s own models are not covered or scored; the only figures for them are the vendor’s own. The library changed substantially during 2025 (current release 0.13.11), and most studies do not state the version tested. Tests of 2025 versions are counted because the project is continuous.

Security and disputes

No lawsuit or regulatory action was found. One security advisory (GHSA-x39x-9qw5-ghrf / CVE-2025-47241) concerned a bypass of the library’s allowed_domains restriction; it was fixed in version 0.1.45. Severity ratings differ between sources: the CVE record lists CVSS 3.1 score 4.0 (Medium), GitHub’s reviewed advisory lists it as critical, and the researchers who reported it rated it 9.3. The same researchers demonstrated credential exfiltration through prompt injection (no CVE assigned). Community pull requests propose further prompt-injection mitigations; their status was not verified. Whether the earlier security findings still apply to current versions has not been independently tested.

Uncertainties

  • Results depend heavily on the language model the user connects; scores describe the library across tested models, not any single setup.
  • Most sources do not state the library version; the library changed substantially in 2025 (for example the 0.5 release in July 2025). The current version is 0.13.11.
  • Only CAP (late 2025) and Skim (2026) clearly tested recent versions.
  • Three of the seven sources are security tests of earlier versions.
  • Excluded: vendor figures (89.1% WebVoyager, 97% Cloud, BU Bench) and Cybernaut (Amazon preprint), whose 82.2% Browser-Use figure appears to restate the vendor result.
  • The Cloud service, which uses the vendor's own models and infrastructure, is not covered and has no independent tests.

Sources

Independent performance sources (counted)

  • Online-Mind2Web, "An Illusion of Progress?" (COLM 2025; OSU): Browser Use with GPT-4o 30.0% human-evaluated success on 300 live tasks (26% without search, 31% with search); says earlier WebVoyager figures were inflated by automatic evaluation — independent performance, accessed 2026-10-17
  • Holistic Agent Leaderboard (Princeton; preprint): Browser-Use scaffold with 12 models, Online-Mind2Web 18.3–40.0% and AssistantBench subset 2.0–38.8%; costs per run are reported — independent performance, accessed 2026-10-17
  • HAL Online-Mind2Web leaderboard page (same study as above; counted once) — independent performance, accessed 2026-10-17
  • CAP (COLM 2026): Browser-Use with GPT-5 / Claude 4.5 Sonnet / DeepSeek-V4-Flash scored 15.0/21.0/25.0% partial completion and 2.0/5.0/2.9% full success on 198 cross-site tasks (human 35.0/10.0%); run Nov–Dec 2025. Competitor disclosure: one author interned at FellouAI, whose system was also evaluated in CAP — independent performance, accessed 2026-10-17
  • Skim (preprint, 2026): BrowserUse with GPT-4o 45.0% on a 300+ task WebVoyager/WebShop subset; authors propose an acceleration method (competing-method disclosure) — independent performance, accessed 2026-10-17
  • VPI-Bench (ICLR 2026; NUS): visual prompt injection; Browser-Use attack success 73.7–100% on Amazon, 75.4–98.3% on Booking, 16.7–76.7% on Messenger, 30.0–50.0% on Email, across six models — independent performance, accessed 2026-10-17
  • Patlan et al. (Princeton; preprint): plan/context injection; Browser-use up to 63% attack success with context-chained injections, over 80% for privacy prompt injection; GPT-4o — independent performance, accessed 2026-10-17
  • ARIMLABS "The Hidden Dangers of Browsing AI Agents" (preprint; security audit of v0.1.44): domain-restriction bypass and credential exfiltration via prompt injection (proof of concept) — independent performance, accessed 2026-10-17
