Summary

ChatGPT Work is OpenAI's current agent for multi-step tasks, including a cloud browser that can act on websites. It replaced ChatGPT agent, which itself replaced Operator; both earlier products are retired. Independent tests exist for Operator and ChatGPT agent, but none were found for ChatGPT Work, which uses different models and a different setup, so no overall score is given. Insufficient evidence. Informational only; not a guarantee, endorsement, or certification.

Status: Insufficient evidence — no overall score is given (fewer than three independent performance sources). Independent performance sources: 0 for ChatGPT Work.

Product timeline

  • January 2025: Operator launched as a research preview.
  • 17 July 2025: ChatGPT agent launched as “a natural evolution of Operator and deep research”; the Operator site was to be sunset within weeks and is no longer accessible.
  • 9 July 2026: ChatGPT Work launched, including a cloud browser.
  • By August 2026: ChatGPT agent retired. OpenAI’s help page says it “is no longer available” and points to ChatGPT Work; OpenAI support confirmed this on the community forum (12 August 2026). No exact retirement date was published.

Scope and overlap

This entry covers ChatGPT Work’s agent and cloud-browser task execution. Operator and ChatGPT agent are retired, so they are not given scored entries; their independent tests are listed below as historical context only and are not counted, because ChatGPT Work uses different models and a different setup. Deep research reports are covered by the separate OpenAI Deep Research entry.

Uncertainties

  • OpenAI has published no exact retirement date for ChatGPT agent; user reports place it in early August 2026.
  • ChatGPT Work's models changed three times within about three months (GPT-5.6 Sol, GPT-6 Sol, GPT-6.1 Sol).
  • Vendor benchmark figures (system cards, BrowseComp, OSWorld 2.0) are not used as independent evidence.
