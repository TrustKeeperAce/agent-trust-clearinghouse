Open Interpreter

Category: Simple analysis · Type: open-source (Apache-2.0) · Scope: local code-executing agent · Repository · Last reviewed: 2026-10-16

Summary

Open Interpreter is an open-source agent that runs code on the user's computer from natural-language instructions. Its repository now tracks a rewrite built on Codex; the earlier Python version continues in a community fork. Independent security studies, mostly preprints and self-published projects, tested the earlier Python version; we found no independent evaluation of the current product, so no overall score is given. Insufficient evidence. Informational only; not an endorsement or certification.

Status: Insufficient evidence — no overall score is given. Independent evaluations of the current product: 0.

Uncertainties

  • Evidence concerns the earlier Python version; the current product is a rewrite and may behave differently.
  • Results in the studies depend heavily on the underlying model.
  • None of the studies found is peer-reviewed.
  • Fix status of the public security reports in the community fork was not checked.
  • No reputable journalism with original testing was found.
