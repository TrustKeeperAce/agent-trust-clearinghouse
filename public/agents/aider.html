Summary

Aider is an open-source command-line tool that edits code in a local git repository using a language model chosen by the user. Eight independent studies that ran it were found (five peer-reviewed). Results depend heavily on the model and task. In most studies that compared agents, Aider completed fewer tasks than OpenHands or SWE-agent with the same model, for example 1.85-16.67% task pass rate on GitTaskBench and 11.2-20.0% of vulnerabilities patched on SEC-bench, although it had lower cost per task. Results on secure-coding benchmarks were mixed. Aider with GPT-5 had the best correct-and-secure score (35.8%) of three agents on MT-Sec and was close to the leaders on SecRepoBench (50.6% secure-pass@1), but had the lowest average correct-and-secure rate (6.7%) on SecureVibeBench. Two CVEs have been published (assigned by VulDB and VulnCheck); the related GitHub issues were open with no fix identified as of 17 October 2026. The latest release is v0.86.2 (February 2026). Scope

The open-source Aider command-line tool (aider-chat), run with a language model chosen by the user, from v0.82.0 (April 2025) through v0.86.2 (12 February 2026) and the main branch (last commit 22 May 2026). The Aider leaderboards (Polyglot, code editing, refactoring) are run by the maintainer and are not counted. Results depend heavily on the language model and task, so they are reported as ranges by model.

Version and status note

Aider's latest release is v0.86.2 (12 February 2026); the main branch was last updated on 22 May 2026.

How sources were counted

The Aider maintainer runs the Aider leaderboards, so those results are listed but not counted. Studies with Aider developers as co-authors would be excluded; none were found. Aggregator sites that republish leaderboard figures are not counted.

Disclosures for counted sources

No counted study has Aider developers as authors. One SecRepoBench author is affiliated with Google DeepMind. MT-Sec and SecRepoBench share authors, as do SecureVibeBench and Sifting the Noise.

Security

Aider runs commands and edits files in the user's repository. CVE-2026-85674: a repository's configuration file can set test or lint commands that run without confirmation, affecting versions through v0.86.2 (CVSS 3.1 7.8, VulnCheck; GitHub issue #5254 open). CVE-2026-10175: prompt injection in Architect mode can lead to injected code being committed (CVSS 3.1 6.3, VulDB; NVD status: Not Scheduled; VulDB states the maintainer did not respond; GitHub issue #5058 open). No fix was identified for either as of 17 October 2026. No legal or regulatory action was found.

Sources

Independent performance sources (counted)

  • SEC-bench (University of Illinois Urbana-Champaign, Purdue; NeurIPS 2025): 80 real vulnerabilities; Aider patched 20.0% (Claude 3.7 Sonnet), 11.2% (GPT-4o), 17.5% (o3-mini); proof-of-concept 1.2% (Claude 3.7); lowest of three agents; patches mostly under 10 lines — accessed 2026-10-17
  • GitTaskBench (AAAI 2026): Aider execution completion 5.56-20.37%, task pass rate 1.85-16.67% across four models (best DeepSeek V3), lowest of three frameworks; lowest cost (under $0.003 per task with DeepSeek V3) — accessed 2026-10-17
  • MT-Sec (University of Maryland; EMNLP 2026 per author homepage): multi-turn secure coding; Aider + GPT-5 (thinking) highest correct-and-secure score (35.8%) of three agents (Aider, OpenHands, Codex); C&S fell by 27.3% in one multi-turn setting. Disclosure: authors overlap with SecRepoBench — accessed 2026-10-17
  • SecRepoBench (University of Maryland; LLM4Code workshop at ICSE 2026): repository-level secure code completion in C/C++; Aider secure-pass@1 39.0-50.6% (best GPT-5), pass@1 56.6-70.1%; OpenHands up to 53.5%; 21% of Aider + Claude Sonnet 4.5 code did not compile. Disclosure: one author affiliated with Google DeepMind (competing Gemini models) — accessed 2026-10-17
  • OmniCode (ACL Findings 2026): with Gemini-2.5-Flash, Aider vs SWE-agent on bug fixing, test generation, code review and style fixing; Python bug fixing 32.4% vs 38.1%, C++ 1.8% vs 8.0%, Java 19.3% vs 14.7%; style fixing 48.6% vs 57.0% (Python) — accessed 2026-10-17
  • SecureVibeBench (Singapore Management University et al.; preprint, v5 June 2026): average correct-and-secure rate Aider 6.7%, SWE-agent 14.3%, OpenHands 13.9% across five models; Aider + Claude Sonnet 4.5 high cost relative to results. Disclosure: authors overlap with Sifting the Noise — accessed 2026-10-17
  • Sifting the Noise (Monash University; ISSTA 2026, Proc. ACM Softw. Eng. 3, ISSTA009): agents triaging static-analysis alerts; Aider false-positive rate 14.3% (OpenHands 14.9%, SWE-agent 14.1% with GPT-5); Aider more stable across policy types — accessed 2026-10-17
  • Multi-Harness RL for Coding Agents (NYU et al.; preprint Oct 2026): six Qwen3-8B-based models on SWE-bench Verified under four harnesses; mean 2.14% solved under Aider (lowest; OpenHands 9.27%). Small research models, not typical use — accessed 2026-10-17
