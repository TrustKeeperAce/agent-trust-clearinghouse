Summary

Cursor's agent works inside the Cursor editor, as cloud agents that open pull requests, and from the command line. Nineteen independent sources were counted (ten peer-reviewed). Fourteen are field studies of public GitHub pull requests from 2025, mostly drawn from one dataset (AIDev): Cursor acceptance was usually second or third of five agents (about 64-77%), lower for performance fixes (42%), and CI runs on its pull requests failed more often than for Copilot or Codex. In benchmarks, Cursor v2.3 tied the highest result on an iOS benchmark (12%) and Cursor Agent ranked first on one GPU-kernel task set. Security tests found prompt-injection and misuse exposure, reduced in newer versions. 28 CVEs (2025-2026) concern agent features; fixes are listed. Informational only; not a guarantee, endorsement, or certification.

Scope

Cursor's agent features from January 2025: agent mode in the editor, background and cloud agents (pull requests on cursor/ branches), and the Cursor CLI agent. Tab completion, inline edits (Cmd-K), chat-only use, Bugbot code review, the 2024 Composer before agent mode, and whole-product adoption studies are not covered. Results depend heavily on the language model chosen and on the task.

How sources were counted

Anysphere material (blog posts, documentation, CursorBench and the Composer 2 Technical Report) is not counted. Pull-request field studies of Cursor's background and cloud agents count; fourteen of the counted sources are field studies drawn largely from one shared dataset (AIDev, 2025), so they are not independent samples, and, as for the other coding-agent entries, each study counts once. Comparisons written by authors from a competing product's company that include that product are listed but not counted. Studies of Tab completion, of models in a Cursor-like harness, or of whole-product adoption are not evidence about this entry.

Security and disputes

The agent can edit files and run terminal commands, with an optional auto-run mode. 28 CVEs published in 2025 and 2026 concern its agent features (MCP configuration, the auto-run allowlist, sensitive-file protection, the terminal sandbox, the CLI and the cloud agent), with CVSS scores from 4.4 to 9.8; Cursor published each through its GitHub security advisories with a fixed version. In July 2025 Cursor apologised for a June 2025 pricing change and offered refunds for unexpected charges. One self-reported incident (April 2026) describes a Cursor agent deleting a production database volume. No filed legal or regulatory action specific to the agent was found.

Uncertainties

  • Fourteen counted sources are field studies drawn largely from the same AIDev pull-request data (2025), so they are not independent samples; as for other coding-agent entries, each study counts once.
  • Field studies identify Cursor pull requests by cursor/ branch names, which mainly capture background or cloud agents, not agent mode inside the editor.
  • Results depend heavily on the model chosen inside Cursor; benchmark figures describe agent and model together.
  • Cursor releases change often (about v1.0 to v3.x during 2025-2026); most field studies state no version.
  • Two competitor-authored comparisons and one whole-product adoption study are listed but not counted.
  • Citation check incomplete — recheck later (Semantic Scholar rate-limited and the arXiv API unavailable; OpenAlex used; several MSR 2026 papers not screened).

  • Why Are AI Agent-Involved Pull Requests (Fix-Related) Remain Unmerged? (Saskatchewan; MSR 2026, arXiv 2602.00164): fix-related Cursor pull requests merged at 68.4% (281 of 411; Codex 81.6%, Copilot 42.4%). AIDev data. Field study — accessed 2026-10-19
  • When AI Agents Touch CI/CD Configurations (Trent; MSR 2026, arXiv 2601.17413): Cursor pull requests that changed CI/CD files merged 4.03 points more often than its other pull requests (p = 0.029); build success 79.10-83.13%. AIDev data. Field study — accessed 2026-10-19
  • A Task-Level Evaluation of AI Agents in Open-Source Projects (Idaho State; MSR 2026): Cursor average acceptance 0.67 across task types (Codex 0.83, Claude Code 0.66, Copilot 0.45); higher share of good commit messages (0.63). AIDev data. Field study — accessed 2026-10-19
  • Reliability of AI Bots Footprints in GitHub Actions CI/CD Workflows (MSR 2026, arXiv 2604.18334): workflow runs on Cursor pull requests succeeded 73.29% (high-level languages) and 65.07% (low-level), below Copilot and Codex (about 93-94%). AIDev data. Field study — accessed 2026-10-19
  • How do Agents Refactor (Alberta; MSR 2026, arXiv 2601.20160): Cursor made the fewest refactorings in Java pull requests (31) and was the only agent with a statistically significant increase in code smells. Small sample. AIDev data. Field study — accessed 2026-10-19
