# decisions/
Each decision is a numbered packet `NNNN-short-title.md` with these sections:

1. **What happened** — facts, each with sources.
2. **What the rules say** — the scoring rules / policies that apply.
3. **Risks / uncertainties** — gaps, conflicts, thin evidence.
4. **Recommendation** — approve / reject / more info, with reasons.
5. **Plain-English terms** — short definitions of any jargon.

Nothing is published until Remington approves the packet.
