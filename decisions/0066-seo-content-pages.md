## What changed
- **Pages:** `public/compare/claude-code-and-openai-codex.html`, `public/compare/coding-agents.html` and `public/compare/research-agents.html`, generated by `build_compare()` in `scripts/build_data.py` from `entries()` only. Each page has:
  - breadcrumb; disclaimer at the top; as-of line;
  - scope list (with fixed caveats) before the table;
  - alphabetical table: overall, grade, four factors, counted (peer-reviewed), last reviewed;
  - "What the evidence does and doesn't show": fixed caveats, plus per-entry counts and the first two uncertainties already published on each entry page;
  - citation guidance and links;
  - JSON-LD `ItemList` (Unordered) and `BreadcrumbList`.
  - No JS, no ratings markup.
- **Research page:** split into academic search tools (Consensus, Elicit) and general research/deep-research agents. Perplexity (Verification) is linked as related, not listed.
- **Breadcrumb:** two levels (Directory › page). There is no compare hub page.
- **Category labels:** 16 YAML files changed (research → Research, verification → Verification, browser/web agent → Browser/web agent, data enrichment → Data enrichment, negotiation → Negotiation, simple analysis → Simple analysis).
  - The index already showed these capitalized.
  - Only `category` changes in agents.json and agents.csv. Scores, grades, status and scope are unchanged.
- **`scripts/check_export.py` checks that:**
  - each page matches a fresh render (no drift);
  - every table cell equals agents.json;
  - every id exists;
  - the disclaimer, as-of date and citation text are present;
  - banned wording (best, top, winner, which is better, stars, ★, #1) is absent from visible text, meta and JSON-LD;
  - JSON-LD is only ItemList/BreadcrumbList, with no rating markup and no script;
  - pages appear in the sitemap and llms.txt, the Compare links exist on index and methodology, and a changelog/feed row exists;
  - index category labels equal the data.

## Plain-English terms
- **Comparison page:** a generated summary of several entries side by side, using the same numbers as each entry page.
- **BreadcrumbList / ItemList:** structured data for "where this page sits" and "which items it lists".
